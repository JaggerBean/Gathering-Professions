## Architecture
- `main.js` — Gatherer integration + API (`game.modules.get("gathering-professions").api`).
  - `gathererGather` hook holds profession materials out of Gatherer's award loop.
  - Wraps `gatherer.prototype._onGather`: node gates (min rank, tools) and condition reweighting (with the gatherer's scarcity relief) run BEFORE a pull is used; empty-by-conditions blocks. After a real gather on a limited node, rolls the no-pull chance and asks the GM to refund.
  - Wraps `gatherer.prototype.toChat`: `resolveCheck` = profession check + perks + Assist, Second Look reroll, partial upgrade, yield, XP, extra draws, rare finds, chat card; returns [main, ...extras]; fires `gatheringProfessionsGatherComplete` {page, actor, results}.
  - Active-GM hooks: node visibility (also on perk Item create/delete), pin tint, timed auto-reset. Socket `module.gathering-professions` types `discover`, `refundPull`, `clearAssist`. Hook `dnd5e.restCompleted` (long rest) clears `rerollsUsed`.
- `rules.js` — professions (world setting `professions`, live `PROFESSIONS` proxy), tiers/ranks, `materialRule`, `checkFormula`.
- `gathering.js` — degrees of success, yield, `upgradePartial`.
- `integrations.js` — Skill Tree points per rank-up, rank mirrors `effectiveRank.<key>` + `professionRank`, rare-find draws (`RollTable#roll`). Re-exports perk functions from perks.js.
- `perks.js` — `PERK_EFFECTS` schema (int sums w/ caps, die max, fraction max, flag any), `normalizePerk`, `actorPerks`, `applyPerksToCheck`, `rareChanceTotal`, `relievedMultiplier`, reroll uses.
- `skilltree.js` — `UNIVERSAL_SKILLS` (30), `THEMES` (6 columns), `prerequisites`, `buildUniversalTree` (perk Items + Skill Tree journal, links, capstone lockouts).
- `assist.js` — Assist offers on the helper actor flag `assist` {pageUuid, at}; `findAssist`, `consumeAssist` (GM socket when not owner); 1 in-game hour expiry.
- `nodes.js` — node flags, gates, check overrides (`toolProficiency` exposed for perks), tool library, visibility/ownership (`sensesNode` with sense perks), pins, builder CRUD.
- `node-ui.js` — Node Manager. `gather-ui.js` — gathering window (perk-aware chances w/ extra dice, Pathfinder odds, Assist button, skill notes in results).
- `conditions.js` / `conditions-ui.js` — conditions, multipliers (+relief), DC modifiers (Weatherproof `ignorePenalties`), miss share.
- `ui.js` — menus, Material/Perk (all effects, grouped)/Professions (+ "Build the universal gathering tree")/Rules editors, and token controls for character profession progress and the linked Skill Tree. `testkit.js` — test kit (builds the universal tree, 2/2 points).

## Key decisions (GM)
- Shared depletion pool per node (Gatherer default). One profession per character; GM changes it.
- ONE universal Skill Tree for all professions: generic names in a radial hexagon web. Six themes are spokes on a 25×25 grid; tier 1 is the inner ring, capstones are at the tips. Links: previous tier on own spoke; cross-theme tier 2/3 links work both ways. Fixed group id `gatheringProfessions`; the tree has `independentSkillPoints`. `layoutVersion` 4 updates links and the group label on GM load without changing page UUIDs. Linked skills and point costs still gate purchases; rank gates are removed. Capstones cost 2 and lock each other out, one per character. Points: 2 at Rank 1 + 2 per rank-up = 10 total at Rank 5. Tree total cost 36, so choices remain.
- User picked effects: check mastery, discovery, tools & utility, and from efficiency ONLY no-pull chance + extra draw on great success (NOT faster refill, NOT XP gain). Actives reset on long rest. Party support = Assist button. Old per-profession test tree replaced via test kit.
- Perk stacking: ints add (caps; no-pull max 90%), dice/fractions take max, flags any. Extra draws = base yield, no XP, no rare. ×0 stays a hard block under scarcity relief. Weatherproof skips only positive condition DC. Sense-all only for nodes with senseRank > 0.
- Nodes: builder makes table + page in journal "Nodes — <Scene>"; overrides = check, DC/yield mods, min rank, any-of tools, rare bonus/table.
- Hidden pins via page ownership; reveal by GM or profession sense rank (+ sense perks).
- Gathering window: materials discovered per PARTY; rares hidden; GM (and Pathfinder) see odds.
- Conditions: weight multipliers; weight lost below base = miss chance (`missShare`); biome = node field else scene flag; season/weather/time from Simple Timekeeping (calendar dawn/dusk) with GM pins; DC modifiers per condition.

## Lessons
- Foundry v14 ApplicationV2 has getter-only `state`; never use `this.state`.
- Gatherer's `_onGather` calls `toChat` without await; window waits on `gatheringProfessionsGatherComplete`.
- Gatherer sends the pull update to the first GM without awaiting it; refunds send the pre-gather count and the GM waits (≤5 s) for the increment before restoring.
- Test Hooks mocks keep the first registration per name; transient `Hooks.on` watchers must not replace module hooks.
